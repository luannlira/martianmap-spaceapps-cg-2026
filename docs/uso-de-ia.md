# Uso de IA

O NASA Space Apps Challenge pede que a equipe **descreva o uso de IA** na submissão. Este arquivo é um **modelo para a equipe preencher**: só a equipe sabe o que foi feito com ferramentas de IA, então os campos abaixo não foram preenchidos por nós.

## Ferramentas utilizadas

| Ferramenta | Para quê | Quem usou |
|-----------|----------|-----------|
| *Claude/Chat GPT* | *Rascunho de documentação, revisão de código, roteiro do pitch* | *Todos* |
